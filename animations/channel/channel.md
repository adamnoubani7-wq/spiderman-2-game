# Channel setup

## Name

**Stick Science Lab**

It says what the channel is: stick-figure animation and real science. It also covers future topics
beyond spiders and superheroes, and it leaves trademarked names out.

Backups, if the name is taken: **Stick Physics Lab**, **What If Lab**.

## Handle

**@StickScienceLab**

Backups: `@StickSciLab`, `@StickScienceLabs`, `@TheStickScienceLab`.

I couldn't check whether these handles are free. YouTube shows that only when you type one into
YouTube Studio (Customization, then Basic info, then Handle).

## Icon

`icon.png` is 800×800, which is YouTube's recommended size. It shows a grinning stick-figure
scientist in goggles, with a spider dangling on a silk thread over a faint web. I checked it cropped
to the circle YouTube uses, at small size.

## Description

```
Real science, explained by stick figures.

Could Spider-Man's web really stop a train? Could a cannonball outrun a cheetah? Every Short takes
one "what if" from movies, games and everyday life and checks it against the actual math and
research, in under a minute.

Animated in code, fact-checked with sources in every description, and built for curious people
who want the answer, not the lecture.

New Shorts every week.

Fan-made science commentary. Not affiliated with Marvel, Sony or any studio whose scenes we
break down.
```

That's 526 characters, well under YouTube's 1,000 limit.

The cannonball example is only a sample "what if" to show the format. Swap it for a real upcoming
topic before you publish. "New Shorts every week" is a promise, so keep it only if you can post
that often.
