# Stick Science Lab website

Static site, no build step. Open `index.html` in a browser, or host the folder anywhere (GitHub Pages, Netlify).
`page.html` is the same page without the html/head/body wrapper; it is the copy published as the private preview artifact.

Designed with the ui-ux-pro-max skill (Hero + Features + CTA pattern, spacious density, its pre-delivery checklist), using the channel's existing brand colours and Poppins/Inter instead of the skill's suggested palette.

`media/` holds 540px copies of the three Shorts and their poster frames.
